Publish, edit, and remove the stories on the public shelf. Everything is stored as plain JSON in this repository — publishing is an ordinary commit, and the site rebuilds itself a minute or two later.

1 Unlock the studio

The studio talks to GitHub on your behalf. You’ll need a personal access token with Contents → Read and write access to this repository.

  1. Open GitHub → Settings → Developer settings → Fine-grained personal access tokens and generate a new token.
  2. Under Repository access, choose Only select repositories and pick this repository.
  3. Under Permissions, set Contents to Read and write — nothing else is needed. (A classic token with the repo scope works too.)
  4. Copy the generated token (it starts with github_pat_…) and paste it below.

The token is kept only in this browser’s local storage and is sent only to api.github.com. Lock the studio — or clear the site’s data — to remove it. You can revoke the token any time on GitHub.
